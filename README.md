# 🚚 Logistics Optimization for Delivery Routes – FedEx

## 📌 Project Overview
This project analyzes FedEx logistics and delivery performance using SQL to identify delay patterns, optimize routes, evaluate warehouse efficiency, and assess delivery agent performance.

## 🎯 Objectives
- Identify shipment delays and root causes
- Optimize delivery routes using efficiency metrics
- Analyze warehouse and agent performance
- Build KPIs for on-time delivery and utilization

## 🗂️ Dataset
The project uses relational datasets including:
- Orders
- Shipments
- Routes
- Warehouses
- Delivery Agents

## 🛠️ Tools & Technologies
- SQL (MySQL)
- Window Functions & CTEs
- Aggregations & KPI Reporting
- PowerPoint for insights visualization

## 📊 Key Analysis Performed
- Data Cleaning & Validation
- Delivery Delay Analysis
- Route Optimization Insights
- Warehouse Performance
- Delivery Agent Performance
- Shipment Tracking Analytics
- Advanced KPI Reporting

## 📈 Key Business Insights
- Certain routes (R003, R019, R002) show poor efficiency and high delays
- Top-performing agents have higher experience and ratings
- Warehouses with high average delays need capacity optimization
- Traffic, weather, and technical issues are major delay reasons
